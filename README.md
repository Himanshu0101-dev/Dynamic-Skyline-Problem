# Dynamic-Skyline-Problem
Problem Statement:
You are given a list of buildings in a city. Each building is represented by three integers:

left (x-coordinate of the left edge),

right (x-coordinate of the right edge),

height (height of the building).

Your task is to compute the skyline formed by these buildings. The skyline is a list of key points where the height of the outline changes.

Example:

text
Input: buildings = [[2,9,10],[3,7,15],[5,12,12],[15,20,10],[19,24,8]]
Output: [[2,10],[3,15],[7,12],[12,0],[15,10],[20,8],[24,0]]
